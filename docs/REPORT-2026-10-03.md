## Goal

kakkoi.dev (source: `KakkoiDev/website`, public), rebuilt and redeployed on
2026-10-03.

## What the lesson teaches
- A static export of a Next.js site and why it fits a personal site.
- Two languages done properly: one root layout per language so `<html lang>` is
  right, every string in a dictionary, `hreflang` and canonical URLs, a shared
  type scale.
- Japanese line breaks: splitting copy into phrases so no line ends on a lone
  character.
- Deploying to GitHub Pages with Actions, the base-path trap
  (`user.github.io/repo/` vs a custom domain) and how the workflow avoids it.
- A Content-Security-Policy without server headers (`<meta http-equiv>`), and
  why `upgrade-insecure-requests` broke the site before HTTPS was ready.
- Debugging stale deploys: caches, and reading the build log to prove what ran.
- A short exercise for students at the end.
